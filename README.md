# Научиться учиться ✍️

Информационная страница о современных подходах к самообразованию, собранная с использованием
методологии БЭМ и вниманием к читабельной типографике.

## ✨ Ключевая функциональность

- Верхний блок сайта с анимированным акцентом и призывом к действию.
- Карточки техник обучения с визуальными иллюстрациями и краткими пояснениями.
- Встроенные выступления TED в видеороликах для быстрого погружения в тему.
- Блоки с фактами и статистикой, оформленные модульной сеткой.
- История Барбары Оакли и метод Фейнмана, которые помогают поддерживать мотивацию.
- Подборка внешних ресурсов и ссылок на социальные сети для дальнейшего изучения.

## 🛠️ Используемые технологии

- **Интерфейс:** HTML5, CSS3, Flexbox, семантическая верстка, встроенные видеоролики.
- **Методология:** БЭМ для масштабируемой структуры стилей.
- **Стили и анимации:** Кастомные анимации по ключевым кадрам, файл normalize.css для единообразного
  отображения.
- **Инструменты автоматизации:** Сборка стилей через LightningCSS, команды NPM, Stylelint, Prettier.
- **Рабочая среда:** Node.js, утилита Serve для локального просмотра и раздачи статики.

## 🚀 Быстрый старт

1. Убедитесь, что установлен Node.js версии 22 или новее.
2. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/IrinaRyazanskaya/how-to-learn.git
   cd how-to-learn
   ```

3. Установите зависимости:

   ```bash
   npm install
   ```

4. Скомпилируйте итоговый CSS-файл:

   ```bash
   npm run build
   ```

5. Запустите локальный сервер и откройте проект:

   ```bash
   npm run serve
   ```

6. Перейдите в браузере по адресу `http://localhost:3000`, чтобы увидеть лэндинг в действии.


## 📚 Что сделано и изучено

- Семантическая HTML5-структура с логичным делением на смысловые секции.
- Организация CSS по независимым БЭМ-блокам и повторно используемым модификаторам.
- Разметка карточек и таблиц фактов через Flexbox.
- Настройка `LightningCSS` для объединения и оптимизации стилей.
- Внедрение `Stylelint` и `Prettier` для единых правил оформления кода.
- Работа с мультимедиа: изображения разных форматов и встроенные ролики YouTube.

## 💡 Решённые задачи и технические сложности

- Объединение десятков CSS-файлов в единый итоговый файл с помощью команды `lightningcss --bundle`.
- Достижение единого внешнего вида во всех браузерах через `normalize.css` и продуманную
  типографику.
- Создание анимированных фоновых элементов (вращающийся квадрат, треугольник Kaufman) при
  минимальной структуре страницы.
- Настройка корректного встраивания видео (`allowfullscreen`, адаптивные медиа-правила).
- Поддержание читаемости кода при росте проекта благодаря структурированным директориям блоков.
